# 部署模式与默认组织

Status: accepted

ESL 引入平台级**部署模式**（单组织 / 多组织）与**默认组织**两个概念：部署
模式由 Bootstrap 按部署场景声明初始值（企业自部署为单组织，技能云提供商为
多组织），运行期可由 Super Administrator 双向切换；默认组织是登录省略组织
名时的解析目标，**在任何模式下都可设置**，单组织模式下必须设置且是唯一可
登录的组织。单组织模式面向企业自身部署——组织内自建团队即可满足协作，无需
多租户；多组织模式面向技能云的多企业注册使用（ADR-0016 的原始场景）。

## 决策细节

1. **默认组织是独立配置，不隶属模式**（在 B1「默认组织仅存在于单组织模式」
   与 B2「独立配置」之间选了 B2）：多组织模式下可不设；设置后 CLI 与管理后
   台登录不填组织名即按默认组织拼装 `<org>_<username>` 账号。单组织模式下
   必须设置。模式切换时该设置保留。因为 B2，术语采用「默认组织」而非「唯
   一组织」——它的语义是 fallback，单组织模式下才附带「唯一活跃」的效果。
2. **多 → 单切换**：Super Administrator 从现有组织中指定一个设为默认组织并
   切换模式（一个原子操作）。其余组织整体冻结：**不引入组织级禁用状态字
   段**，「不可登录」由平台模式推导；冻结组织的技能、仓库、成员原样保留，
   切回多组织模式后恢复可用。现有 Provisioning State 与 Organization
   Deletion State 不受影响。
3. **单组织模式的登录边界**：仅默认组织成员可登录；Super Administrator 的
   管理后台登录不受限（否则模式切换成为单向门）。切换生效时刻，其余组织成
   员已持有的 token **立即失效**——认证中间件按请求校验调用者组织归属，不
   等自然过期。
4. **组织注册**：单组织模式下服务端**硬拒绝**新注册申请（返回明确错误），
   前端仅同步隐藏入口；切换时刻已存在的待审批申请**保持挂起、不自动拒绝**
   ——自动拒绝不可逆，挂起无损，切回多组织后继续处理。
5. **匿名平台信息端点**：新增无需登录的端点（如 `GET /api/public/platform-info`），
   返回 `{ mode, defaultOrg }`。CLI `esl login` 先查它：有默认组织就不问组
   织名，没有（多组织且未设）才要求填写；两种模式行为统一，CLI 不自行区分。
   组织名对匿名访问者可见是接受的成本（企业内网部署场景无碍）。
6. **默认组织 Bootstrap（声明驱动，两种模式通用）**：以环境变量声明组织名与
   Organization Admin 初始凭据（单组织模式必填、多组织模式可选且必须成对声
   明）；Bootstrap 直接以声明值触发 Tenant Organization Provisioning 创建
   该组织（触发源由「注册申请审批通过」变为「Bootstrap 声明」），开通完成即
   成为默认组织。多组织模式未声明则空起步，不预置任何组织。部署模式是初始值
   而非终身判决，部署后仍可双向切换。
7. **默认组织守卫**：默认组织不可直接删除——必须先更换默认组织或切回多组
   织模式（否则单组织模式下删除默认组织 = 平台全员死锁）。单组织模式下更
   换默认组织等同于整体换锁（原组织立即冻结、新组织立即可用），允许但要求
   显式确认。

## 背景

ADR-0016 与 ADR-0020 落地后，平台被固定为多组织形态：登录必填组织名、公开
注册入口常开。企业自部署场景中这些都不需要——单一组织内用 Organization
Team 即可完成协作划分，注册入口反而是多余的攻击面。补齐单组织形态时，核心
分歧在默认组织的归属：若只在单组织模式下存在（B1），「单组织模式」就要携带
独立的指定动作；选 B2 后，模式只管「允许多少组织登录」，默认组织只管「省略
组织名时解析到哪」，两个概念正交，单组织模式退化为「其余组织全部冻结」的
特例，心智负担最小。

## Consequences

- 登录契约变更：`/api/auth/login` 与 `/api/console/login` 的 `org` 字段在设
  有默认组织时（任何模式）变为可省略，服务端按默认组织拼装并校验归属；省略
  时不存在跨组织歧义——按默认组织拼 `<default>_<username>`，失败即失败。
- CLI 登录流程变更：`esl login` 先查匿名平台信息端点再决定是否询问组织名，
  `--org` 仍可显式指定覆盖默认组织。
- 认证中间件新增组织活跃性校验（单组织模式下逐请求校验调用者属于默认组
  织），承载 token 立即失效语义。
- 组织申请 API 在单组织模式下返回模式特定错误；管理后台登录页与注册页按
  平台信息端点的返回隐藏/展示注册入口与组织输入框。
- 组织删除 API 新增默认组织守卫；默认组织更换操作要求确认交互。
- Bootstrap 按声明直接 Provisioning 默认组织（单组织必填、多组织可选声明）；
  Bootstrap Reset（ADR-0018）流程不变，重置后按 `.env` 中的声明重新初始化。
