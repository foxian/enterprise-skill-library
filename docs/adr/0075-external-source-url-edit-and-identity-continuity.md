# 外部技能 URL 编辑与身份连续性

Status: accepted

2026-11-04 确认：外部引用技能允许有管理权限的用户修改来源 URL 和技能目录，并沿用同一个 Skill ID、Skill Identity 和已有版本历史。此决定替代 ADR-0074 中首次成功发布后锁定仓库地址、更换仓库地址必须创建新引用的限制，让管理员能够将既有技能切换到新的仓库、fork 或同一仓库中的另一个技能目录，而不丢失原有版本历史。

- 保存 URL 前验证新来源，并展示技能名称、description 和许可证，供管理者检查来源。
- 保存 URL 本身不创建 Skill Release；后续同步检测到有效内容变化且校验通过后，才在原技能下新增版本，继续递增 patch。
- 内容相同不新增版本；已有 Release 保持不可覆盖，失败时保留最后一个成功版本。
- 本决定调整仓库 URL 与技能目录的可编辑性；跟踪分支仍在首次成功发布后锁定。许可证确认仍遵循 ADR-0074。

## 引入时的名称与冲突处理

2026-11-04 确认：创建外部引用时自动读取上游技能名称，不再要求用户额外填写短名；平台内部仍保留用于定位和安装的 Skill Identity。此规则替代 ADR-0074 中由用户填写或修改短名以解决冲突的交互。

- 同一 Namespace 内名称已被占用时，阻止重复引入，提示名称冲突并提供已有技能入口。
- 不自动添加名称后缀，不覆盖已有技能，也不因名称相同自动将新来源绑定到已有技能。
- 引入后上游改名不自动改变 ESL 内的技能身份；编辑 URL 仍沿用原身份和版本历史。

## 描述展示与低频 URL 编辑

2026-11-04 确认：引入预览和管理编辑界面都展示上游 description，描述保持只读，不提供本地覆盖描述的输入框。

- 修改 URL 时展示新来源描述供核对；同步成功后更新正式展示的描述，同步失败则保留原描述。
- 上游未提供描述时明确显示“上游未提供描述”。
- 通常保持来源 URL 不变，仅在少数需要切换来源的情况下修改；界面以查看技能信息为常态，提供显式编辑入口。

## 当前来源地址契约

根据现有抓取器与网络校验核实：仓库 URL 为无需凭据即可读取的公网 HTTPS Git 克隆地址。代码不强制要求 `.git` 后缀，实际以 Git 服务提供的可用克隆地址为准；使用仓库平台提供的 HTTPS 克隆地址，避免依赖重定向。

仓库 URL、跟踪分支和技能目录分别填写；技能位于仓库根目录时目录留空，分支留空时在创建预览阶段解析默认分支。GitHub 的 `/tree/`、`/blob/` 页面地址、`SKILL.md` 文件地址及 ZIP 下载地址不作为仓库克隆 URL 使用。当前外部引用入口不支持 SSH、普通 HTTP、私有凭据仓库或内网地址。

## 新建与编辑的必填规则

2026-11-04 确认：新建时必须明确归属 Namespace、仓库 URL 和技能位置。Namespace 默认选择当前个人或组织；技能位置通过“仓库根目录”与“仓库子目录”选择明确，只有子目录模式要求填写相对路径。分支可留空，在预览时识别默认分支。

名称与 description 自动读取，不提供额外手填框；可见性默认私有，同步计划提供默认值。首次发布前必须完成许可证确认；新来源许可变化时重新确认。

编辑时预填当前配置，不要求用户重新填写资料。来源 URL 与技能目录通过显式编辑入口修改，验证失败保留原配置；Namespace 和跟踪分支只读。单独调整同步计划或可见性不要求重新验证来源 URL。

## 许可证发现、展示与确认

2026-11-04 确认：系统从上游文件获取许可线索并展示依据，不使用 AI 猜测，不默认补充 MIT 或其他许可证。

- 预览发现所选技能目录及其祖先目录中的候选许可与署名文件，展示文件路径与原文，由管理者选择适用于该技能的文件；选中的目录外文件沿用 ADR-0074 的打包与变化检测规则。
- 优先根据取得的 LICENSE、LICENSE.md、LICENSE.txt、COPYING、COPYING.md 正文识别常见许可证；未识别成功时参考上游 release.json 的 license 声明，明确展示来源。
- 自动识别只是检测线索，不表示系统已经确认该许可适用于技能或允许按所选范围分发；首次发布前要求管理者显式确认。
- 检测不到明确依据时提示补充或选择上游许可文件，阻止首次发布；既有版本保持可用。
- 上游自定义许可或仅有 SKILL.md 中的许可说明不能被静默转换为某个常见许可证；现有正文规则无法识别时明确展示未识别状态与可查看的文件。
- 新来源许可变化或许可文件变化时沿用重新确认流程，不把先前确认自动应用于变化后的许可内容。
