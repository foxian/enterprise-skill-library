# 组织管理成员与技能管理团队的权限边界

Status: accepted（部分取代 ADR-0036：管理成员身份不再由 `all-managers` 推导）

组织管理成员与技能管理团队是两个不同概念：`all-managers` 是所有组织成员默认加入的技能授权团队，不推导任何组织身份；`org-managers` 才承载管理成员身份。管理成员可以按平台成员加入策略添加普通成员，管理除 `Owners` 与 `org-managers` 成员关系之外的组织团队，并对本组织 Namespace 下全部技能拥有独立的完整管理权，包括源码、发布、可见性、授权、改名、归档和删除；但不能变更成员身份，也不能把成员移出组织。所有者成员继承上述能力，并独占成员身份、组织成员移除、受保护身份团队、组织设置和组织删除等组织治理能力。

## Consequences

- 所有组织成员加入组织时自动进入 `all-readers`、`all-writers` 和 `all-managers`，离开时自动移出；`all-managers` 默认不授予任何技能权限，必须按技能显式授权。
- `org-managers` 与 `Owners` 的成员关系不通过通用团队成员接口维护；普通成员与管理成员之间的身份变更只能由所有者成员执行。
- 管理成员离开组织时失去组织团队关系、组织级技能管理权和团队授权所得权限；技能上的直接成员授权按其既有规则处理。
- 技能删除继续遵守显式确认、依赖保护、审计和不可恢复规则；本 ADR 只扩大可执行者，不改变删除语义。
- 组织只要求至少保留一名所有者成员，不要求必须存在管理成员。

## Considered Options

- **用 `all-managers` 承载管理成员身份**：拒绝。它是技能权限团队，所有成员可能共享该技能授权，不能同时作为组织治理身份的来源。
- **让管理成员拥有成员身份变更或组织移除能力**：拒绝。这样会把技能与团队运营权限扩大为组织治理权，破坏所有者成员作为治理边界的职责分离。
