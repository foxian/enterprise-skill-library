# 05 — `info`/`search` `--json` + human-readable info

**What to build:** `esl info` shows a human-readable summary by default (name,
description, versions, Git repo path) and emits the full structured record with
`--json`. `esl search` gains a `--json` mode that emits a structured result
list. Data output goes to stdout; human messaging goes to stderr.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] `esl info` shows a human-readable summary by default.
- [ ] `esl info --json` emits the full structured record.
- [ ] `esl search --json` emits a structured result list.
- [ ] Data output goes to stdout and human messaging to stderr.
