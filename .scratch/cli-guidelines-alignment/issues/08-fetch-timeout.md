# 08 — Fetch timeout

**What to build:** Network requests time out after a sensible default of 30
seconds so an unreachable server does not hang the terminal forever. The
timeout can be overridden via an environment variable for slow networks.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Network requests time out after a sensible default.
- [ ] The timeout can be overridden via an environment variable.
- [ ] A timed-out request fails with a clear, human-readable error.
